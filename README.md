Agrisense AI
 Multimodal AI Framework for Crop Stress Detection & Yield Prediction

AI-based framework for early crop stress detection, yield prediction, and smart agricultural recommendations.
Uses satellite vegetation indices (NDVI/NDRE), weather, soil, IoT, and crop data.
Includes Random Forest and XGBoost models for stress classification and yield prediction.
Provides an explainable rule-based advisory system for irrigation, soil, and crop-stress alerts.
Currently uses synthetic data with integration points for Sentinel-2, NASA POWER, and SoilGrids.
Tech Stack: Python, Pandas, NumPy, Scikit-learn, XGBoost, Joblib, Matplotlib.
